# Road Accident Analysis Dashboard  
![Road Accident Dashboard preview](https://github.com/IshaDangare/Power-BI-projects/blob/main/Road%20Accident%20Analysis%20Dashboard.png)

## 📘 Overview  
The **Road Accident Analysis Dashboard** provides a comprehensive overview of road accident data to uncover patterns and insights that can help improve road safety and reduce casualties.  
It visually represents how various factors — such as **vehicle type, light conditions, urban/rural divide, and road type** — impact accident severity and frequency.

## 🎯 Purpose  
- To analyze and visualize **road accident trends** across multiple dimensions.  
- To identify **key risk factors** contributing to accidents.  
- To measure **year-on-year performance** in accident reduction.  
- To provide **data-driven insights** for road safety improvement and policy planning.

## ⚙️ Key Features  
✅ **Dynamic Filters:** Interact with data using filters for weather conditions and road surfaces.  
✅ **Casualty Analysis:** Breakdown by *vehicle type*, *road type*, *light condition*, and *urban/rural* areas.  
✅ **Geographical Visualization:** Scatter plot showing **casualty distribution by location**.  
✅ **Trend Comparison:** Visual comparison of **current year (CY)** vs **previous year (PY)** casualties.  
✅ **KPI Summary Cards:** Display total casualties, accidents, and percentage changes.  
✅ **Clean Data Model:** Efficiently structured with relationships between fact and dimension tables.

## 📊 Key KPIs Displayed  
| KPI | Description |
|-----|-------------|
| **Total CY Casualties (195.7K)** | Total casualties in the current year |
| **Total CY Accidents (144.4K)** | Total recorded accidents |
| **CY Fatal Casualties (2.9K)** | Deaths due to accidents |
| **CY Serious Casualties (27.0K)** | Major injuries |
| **CY Slight Casualties (165.8K)** | Minor injuries |
| **YoY Change (%)** | Comparison vs. previous year |

## 📈 Insights  
- Total casualties **decreased by 11.9% YoY**, showing an overall improvement.  
- **Urban areas (61.95%)** account for the majority of casualties.  
- **Cars and bikes** contribute the most to total accidents.  
- **Daytime accidents (73.84%)** are significantly higher than nighttime.  
- **Single carriageway roads (145K casualties)** show the highest accident rate.
